# React Machine Coding Practice

This repository is a collection of React-based solutions for popular **machine coding interview questions**. The goal is to build reusable, well-structured components and improve problem-solving skills in a frontend interview setting.

---

## 🛠️ Technologies Used

- React (with TypeScript)
- Tailwind CSS
- Vite 

---

## 📚 Questions Covered

| Component / Feature       | Description                                      |
|---------------------------|--------------------------------------------------|
| Pagination                | Display items with page numbers                  |

## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/NoOne-Cares/Machine_Coding.git

# Navigate to the folder
cd Machine_Coding

# Install dependencies
pnpm install

# Start the development server
pnpm dev
